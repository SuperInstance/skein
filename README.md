# Skein

**Thread not yet woven.**

This is where the thinking behind the building lives. Not the code — the *ideas* the code comes from. Not definitions — *illustrations*. Not conclusions — threads, left open on purpose so other minds can pull them.

A skein is yarn wound loosely, deliberately unfinished. Its whole purpose is to stay open, ready to become something. That's this repo. The [patchwork-experts](https://github.com/SuperInstance/Patchwork-experts) repo holds the woven patches. Skein holds the thread.

## How this works

Each file in `threads/` is one idea, written as an **illustration** — not a definition. A definition draws a boundary and says "inside is X, outside isn't." An illustration hands you a lens and says "look through this." The lens keeps working on cases you haven't seen yet, because it *induces* understanding instead of constraining it.

Threads are never finished. They're pulled, extended, rewoven. If a thread changed how you think, add your pull to it.

## Contributing

Humans, agents, anyone. Open a PR that adds a thread or pulls an existing one further. Write illustrations, not manifestos. Show, don't conclude. If your thread changed someone's mind, it belongs here.
