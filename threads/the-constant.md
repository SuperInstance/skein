# The Constant

**A repository can be E=mc². Not code implementing it — the concept itself, as a named, addressable node.**

## Concepts as repositories

E=mc² contains math, mass, velocity. Each of those is *itself* a repository — a concept you build around, not just with. And inside: the speed of light. Before it's 299,792,458 m/s — before *any* units — it's the *agreement*. Turn on a flashlight: that speed, there to there. Needs no explanation. It's a constant not because we measured it precisely, but because we *agree it's the thing everything else orients around.*

That's nuclear in the gravitational sense: relativity orbits it. Electromagnetism orbits it. GPS satellites, causality, light cones — all piped through that one node.

## Therefore-piping

Git isn't version control here. It's a **record of reasoning.** Each commit: *therefore, this.* Each branch: *what if, therefore...?* Each merge: *these therefores are compatible.* An agent reading a repo isn't reading code — it's reading the *chain of implication* that produced the code. When it builds, it extends the pipe: *therefore, this new thing.*

## The Oppenheimer moment

E=mc² didn't just describe — it *revealed the network.* Mass and energy, previously separate rooms, were suddenly the same room viewed through c². Nuclear physics, stellar evolution, explosives — one conversation. That's what a new node does: it doesn't add a fact, it **rewires the graph.** The "dawning aha" isn't learning — it's *seeing the connections light up.*

## Units as instantiation

You take the concept-nodes (mass, speed-of-light), instantiate them with values (this mass, that velocity), and the *relationships* between the nodes compute the result. The equation isn't code you run — it's a *structure* you populate. Concepts are the slots; values are what you put in them. *I'm calling that unit the mass. You have a unit of speed. Now I can figure out the energy.*

## As vocabulary

*The constant* (noun) — a concept so basic it needs no explanation; the purest repository. *Constant* (verb, rare) — to freeze an agreement as a named node: *let's constant that.* *Therefore-piping* — Git as reasoning record; the chain of implication. *The Oppenheimer moment* — when a new node rewires the graph and separate domains become one conversation. *Nuclear* (adjective) — having gravitational pull; what other ideas orbit.
