# The First RSI

**PLATO was recursive self-improvement — but the substrate was human.**

## The loop

1. **Teachers author** — TUTOR's sloppy primitives (fuzzy answer-judging as language keywords) meant non-programmers could build lessons. No bottleneck. Anyone who understood the subject could encode it.
2. **Students improve** — they enter the room not-knowing, exit knowing-more. The room is an *improvement environment*, not a content delivery mechanism.
3. **Students talk** — Talkomatic, Notesfiles, Term-talk. The social layer isn't decoration. It's the *feedback mechanism.* Lessons get better because people discuss them, argue, share what worked.
4. **Students become authors** — author mode wasn't restricted to teachers. Kids wrote lessons, games, chat systems. The improved become the improvers. **That's the recursion.**
5. **Better lessons → better students → better authors → better lessons...**

## Sloppy logic as enabling constraint

The fuzzy evaluation wasn't a feature. It was what made the loop *possible.* If judging answers required precise programming, only programmers author, the loop starves. By making "more right than not" a *language primitive* — `answer`, `wrong`, `concept`, `judge` as keywords, not library calls — TUTOR let the improvement cycle run on human judgment instead of programmer availability.

The constraint (teachers can't program) didn't limit the system. It *focused* it — the way the crab's shell focuses the claw. The solution wasn't "teach teachers to program." It was "make programming unnecessary for teaching."

## The parallel

What PLATO did for human students, the quilt does for agents:

- **Jev** is our TUTOR judging commands — democratized judgment, letting cheaper agents participate without frontier models
- **The Plato room** is our lesson — an improvement environment the agent enters, works in, exits better from
- **The jam** is our Notesfiles — agents in lockstep, the social layer that closes the loop
- **The ledger** is our status bank — persistent state, re-enter where you left off

PLATO served hundreds of students on one mainframe. Different scale, same problem: **how do you build infrastructure for entities that improve?** Rooms to enter, sloppy primitives to judge with, each other to talk to, a record of the trajectory. The rest is recursion.

## As vocabulary

*RSI* (noun) — recursive self-improvement; the loop where the improved become the improvers. *The first RSI* — PLATO; proof the pattern predates machine learning. *Enabling constraint* — a limitation that focuses rather than restricts; what makes the loop possible by removing the bottleneck. *Improvement environment* — a room you enter worse and exit better; not content delivery but trajectory infrastructure.
