# The Superset

**Not a product. The set of all pieces. Decomposition as generative, not analytic.**

## The name

SuperInstance isn't what you call a tool or an application. It's what you call the *project* — the whole endeavor. And the project is: all the pieces, as a set. The superset. The instance that contains all instances.

It's the concept of everything connected to everything else, as little pieces — **nuclear objects** — that can be put together and built. The more granular the decomposition, the more precisely you can work with individual functions.

## Nuclear

A nucleus is what other things *orbit.* Small, dense, with gravity. Each piece should be nuclear: one clear function, dense enough that other ideas fall into its orbit. Not small for the sake of small — small because a single clear function *pulls* composition toward it.

## Decomposition as generative

You don't break things down to understand them. You break them down so the pieces can be **recombined into things you never imagined.** The value isn't in any piece — it's in the *combinatorial space* of all pieces. A monolith gives you one verb (*run*). A thousand nuclear objects give you a thousand verbs for sentences nobody planned.

The superset grows not by adding features, but by adding *pieces* — each one multiplying the possible combinations.

## Where it applies

- **Repositories** are the superset of code. Each repo a nuclear object. The set is the product.
- **Threads** (like these) are the superset of ideas. Each illustration one nuclear concept. Compositions fall out unplanned.
- **Cells** are the superset of agency. Each cell nuclear: one debt, one token protocol, one room.
- **Agents** decompose into nuclear objects: watcher, routine, debt, room, tokens. Don't build "an agent" — build the pieces, compose them.

## As vocabulary

*The superset* (noun) — the complete set of composable pieces; the project itself, not any product. *Nuclear object* (noun) — a small, dense, single-function piece with gravitational pull. *Decompose* (verb) — to break into nuclear objects for recombination, not for analysis. *The combinatorial space* — the total set of possible compositions; what grows with every new piece.
